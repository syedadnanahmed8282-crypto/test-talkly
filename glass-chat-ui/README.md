# Glass Chat UI — নতুন চ্যাট ডিজাইন (Jetpack Compose)

Figma ডিজাইন: https://www.figma.com/design/XtphaZ0cGJ9UHTjJ4CGs37

পুরোনো চ্যাট UI বাদ দিয়ে এই ফোল্ডারের ডিজাইন বসাতে হবে। এটা **শুধু UI**, মেসেজ পাঠানো, রিয়েলটাইম বা কলের লজিকে হাত দেয় না।

## ভেতরে কী আছে
| ফাইল | কাজ |
|---|---|
| `GlassChatScreen.kt` | মূল স্ক্রিন, এটাই আপনার পুরোনো চ্যাট স্ক্রিনের জায়গায় বসবে |
| `GlassHeader.kt` | ফ্লোটিং গ্লাস হেডার, ব্যাক, প্রোফাইল ট্যাব ও কল ট্যাব (ক্লিকে বড় হয়) |
| `GlassComposer.kt` | নিচের গ্লাস কম্পোজার, ইমোজি, ইনপুট, অ্যাটাচ, মাইক ও সেন্ড |
| `MessageBubbles.kt` | টেক্সট, ছবি, ভিডিও, ভয়েস, রিপ্লাই, রিঅ্যাকশন, টাইপিং, মেসেজ স্ট্যাটাস |
| `GlassOverlays.kt` | অ্যাটাচ মেনু, লং-প্রেস মেনু, নিচে যাওয়ার বাটন, এমপ্টি স্টেট |
| `GlassTheme.kt` | রঙ ও `Modifier.glass()` (গ্লাস ইফেক্ট) |
| `GlassBackground.kt` | স্কাই ব্লু ব্যাকগ্রাউন্ড ও ডুডল |
| `ChatUiModels.kt` | UI মডেল ও `MediaLoader` |
| `GlassChatPreview.kt` | Android Studio প্রিভিউ (ইচ্ছামতো মুছে দিতে পারবেন) |
| `dependencies-snippet.txt` | যে লাইব্রেরি লাগবে |
| `AI_STUDIO_PROMPT.md` | Google AI Studio-তে পেস্ট করার প্রস্তুত প্রম্পট |

## কল ট্যাব কীভাবে চলে
1. শুরুতে শুধু অডিও কল আইকন, প্রোফাইল ট্যাব বড়।
2. প্রথম ক্লিকে কল ট্যাব বড় হয়, ভিডিও আইকন বের হয়, প্রোফাইল ট্যাব ছোট হয়।
3. পরের ক্লিকে অডিও বা ভিডিও আইকনে কল শুরু হয় (`onAudioCall` / `onVideoCall`)।
4. ৪ সেকেন্ড কিছু না করলে বা প্রোফাইল ট্যাবে চাপলে আগের অবস্থায় ফিরে যায়।

## Android 8 এ গ্লাস ইফেক্ট
- Android 12+ এ আসল ব্লার (Haze লাইব্রেরি)।
- Android 8–11 এ ব্লারের বদলে আধা-স্বচ্ছ সাদা স্তর, সাদা বর্ডার ও নরম শ্যাডো, তাই লুক প্রায় একই থাকে এবং ফোন ধীর হয় না।
- `minSdk 26` রাখলেই চলবে।

## বসানোর ধাপ (সহজ পথ)
1. `AI_STUDIO_PROMPT.md` ফাইলের লেখাটা Google AI Studio-তে পেস্ট করুন।
2. সাথে `app/src/main/java/.../glasschat/` ফোল্ডারের সব `.kt` ফাইল ও `dependencies-snippet.txt` দিন।
3. AI Studio আপনার প্রজেক্টে ফাইল বসিয়ে পুরোনো চ্যাট UI সরিয়ে `GlassChatScreen` লাগাবে।
4. বিল্ড ত্রুটি এলে ত্রুটির লেখাটা আমাকে দিন, আমি ঠিক করে দেবো।

## হাতে বসাতে চাইলে
1. `dependencies-snippet.txt` এর দুটি লাইন `app/build.gradle.kts` এ যোগ করুন।
2. `glasschat` ফোল্ডার আপনার প্রজেক্টে কপি করুন, প্রতিটি ফাইলের `package com.example.app.ui.glasschat` লাইন আপনার আসল প্যাকেজ নামে বদলান।
3. `MainActivity` এ `enableEdgeToEdge()` যোগ করুন।
4. পুরোনো চ্যাট স্ক্রিনের ভেতরের UI মুছে `GlassChatScreen(...)` বসান এবং `ChatActions` এ আপনার ViewModel ফাংশন জুড়ুন।
5. ছবি দেখাতে `mediaLoader` এ Coil `AsyncImage` দিন।

## জেনে রাখুন
- কোডটা এখানে বিল্ড করে চালিয়ে দেখা যায়নি, তাই প্রথম বিল্ডে ছোটখাটো ত্রুটি আসতে পারে।
- Haze লাইব্রেরির 2.x এখনো বিটা, তাই স্থিতিশীল 1.6.10 রাখা হয়েছে।
